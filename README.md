# MyZCode

Собственная сборка ZCode Desktop с встроенной русской локализацией.

## Структура

- `origin/ZCode-main/` — исходники ZCode (с github, ветка main) с вшитым ru-RU
- `translate/` — инструменты русификации: словарь `ru.json` (~7150 строк, включая
  все 1023 новых строки 3.16.3), патчер собранного asar, генератор `ru-RU.ts`,
  полная документация процесса — см. `translate/README.md`
- `plugins/` — сторонние инструменты, кандидаты на интеграцию/изучение:
  - `zcode-account-switcher` — переключение аккаунтов ZCode (jinpeng-vnode)
  - `ZCode-Agent-Kit` — прокси ZCode-токенов для сторонних ассистентов (ZepiGit)
  - `zcode-account-manager-public` — GUI-менеджер аккаунтов (Asati-git)

## Совместное использование с оригинальным ZCode (один ПК)

| Что | Поведение | Решение |
|---|---|---|
| Данные `~/.zcode` (настройки, аккаунты, проекты) | Общие — CLI работает в `~/.zcode` по дизайну | Полная изоляция: env `ZCODE_DATA_BASE_DIR=<свой путь>` перед запуском MyZCode |
| Протокол `zcode://` | Один обработчик на схему в Windows | Решено в коде: перезахват при старте логина + пересылка чужих колбэков (`desktopOAuthDeepLink.ts`) |
| Telegram-бот (один токен) | Опрос токена двумя приложениями конфликтует | Один хозяин бота на ПК: оригинал закрыть полностью (включая трей), бот остаётся в MyZCode и отвечает по-русски |

## Что вшито в исходники (2026-10-24)

ru-RU добавлен третьей локалью по всем точкам приложения:

- `shared`: тип `Locale`, zod-схемы настроек, каталог меню/трея/дока (48 строк),
  community-URL (ru → en), схема rewards-моста
- `ui`: каталог `ru-RU.ts` (6983 ключа из ru.json, покрытие 100%), IntlProvider
  (регистрация + системная локаль ru), переключатель языков (цикл 中→En→Ру),
  пикеры в настройках и сайдбаре, ErrorBoundary, шаринг/ошибки, фидбэк,
  маркетинговые адаптеры, rewards-webview (ru → en перед отправкой в страницу)
- `desktop`: «О программе», автообновление (release notes: ru → en → zh),
  системная локаль (ru-системы распознаются), **F12 = DevTools** в меню «Справка»
- `services`: телеграм/ф_lsh/weixin-боты — полный русский каталог бота (113
  сообщений), форматтер ответов, права (Разрешить/Отклонить...), режимы,
  гранулярность ответов, метки удалённых папок, все ветвления locale

Непереведённое осознанно: coding-plan webview (сервер отдаёт только zh/en),
описания встроенных скиллов (фолбэк на английский), веб-версия.

## Сборка

```bash
cd origin/ZCode-main
pnpm bootstrap          # Node 24.14.0, pnpm 10.33.2 (см. mise.toml)
pnpm --filter @zcode/desktop build
```
